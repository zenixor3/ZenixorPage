# Зениксор — страница ссылок

Файлы: `index.html`, `style.css`, `app.js`, `icons.js`, `links.json` (тут хранятся кнопки).

## Как выложить (GitHub Pages, бесплатно)
1. Создай репозиторий на GitHub, например `zenixor.github.io`, и загрузи туда все файлы.
2. Settings → Pages → Source: `main` / root. Сайт откроется по адресу `https://<логин>.github.io/`.
3. Ссылку на сайт поставь в шапку профиля TikTok.

## Редактор
- 5 раз подряд нажми на круглую «Z» → появится строка поиска → введи пароль.
- Можно добавлять, менять, удалять и двигать кнопки (↑ ↓).
- Правки сразу видны в твоём браузере. Чтобы их увидели **все**, нажми «Опубликовать»:
  - первый раз попросит логин, репозиторий и токен GitHub
    (github.com → Settings → Developer settings → Fine-grained tokens → доступ только к этому репозиторию,
    Permissions → Contents: Read and write);
  - через ~1 минуту сайт обновится у всех.
- Без GitHub: «Скачать JSON» и замени `links.json` на хостинге вручную.

## Где что менять
- Тексты профиля и теги — `index.html`.
- Предсказания для «Крутануть» — массив `SPIN_IDEAS` в `app.js`.
- Пароль: в `app.js` лежит SHA-256 хеш (`PASSWORD_HASH`). Новый хеш можно получить командой
  `printf 'НовыйПароль' | sha256sum`.
